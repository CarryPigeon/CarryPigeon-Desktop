# 16｜统一界面语言（无缝工作台）

版本：v2.0  
日期：2026-10-22

> 本文档把「无缝工作台」固化为全应用统一界面语言：以聊天主窗口为基准，页面承载在一张悬浮玻璃面上，
> 区域之间无间距、无分割线，头部与行列表采用紧凑节奏。
> 落地实现以 `src/App.vue` 的 token、`src/styles/_ui.scss` 的 mixin、`src/shared/ui` 的组件为单一真源；
> 本文只解释规则与取舍。

## 1. 视觉基调

- **单张悬浮玻璃面**：页面背景（暖纸/石墨 + 网格）透过 8px 留白可见；整页由一张玻璃面承载，区域
  （页头 / 侧栏 / 内容 / 页脚）自身透明，区域之间**无间距、无分割线**。玻璃面固定到视口，页面内容
  在其上滚动，外轮廓只由 8px 留白、18px 圆角与柔和阴影承担。
- **克制的层级**：页面级只有一张玻璃面；内嵌卡片/分组（模块卡、频道卡、表单模块、消息气泡等）使用
  1px 边框与更实的底色，不再叠加模糊与投影。
- **紧凑 chrome**：页头是 14px/700 的控制台，不是大标题区；分区标题 14px/900；导航/简单行 30px 高、
  4/6 行距；富内容行 8/10；文件行 44px。
- **安静的行列表**：行 hover 只变底色，不做上浮/位移；行与行之间不画分隔线，用行距、hover 与
  选中态（highlight 底 + inset 2px 竖条）区分。
- **品牌识别保留**：domain 色条、LED、等宽 ID、大小写字距微标签继续使用；只统一表面/骨架/排版语言。

### 1.1 保留项与例外

- 登录 / 注册：与主窗口页面一致使用 `cp-workspace` 无缝工作台骨架（整页一张共享玻璃面）；注册页为左连接栏 + 右表单栏的无缝双栏，登录页为玻璃面上的居中向导列；内部继续复用同一套 token 与控件（`--cp-page-gap` 仅作为向导内容节拍，不再作页面留白）。
- 浮层：对话框、抽屉、右键菜单、Toast、UpdatePrompt、ThreadPanel、通知/提及面板、文件预览、截图遮罩、
  popover 子窗口继续使用 `cp-glass-panel`（半透明 + 模糊）。
- 控件边框：输入框、按钮、分段控件、状态条、气泡、表格列头等功能性边框保留；“无分割线”只针对版式。

## 2. Token（`src/App.vue`）

| Token | 值/用途 |
|---|---|
| `--cp-workspace-pad` | 8px，页面留白；与玻璃面 `inset` 同值 |
| `--cp-page-pad` / `--cp-page-gap` | 14px / 12px，仅用于居中/引导类页面；主窗口页面不再使用 |
| `--cp-section-head-gap` | 14px，分区头下边距 |
| `--cp-radius-lg` / `--cp-radius-card` / `--cp-radius-control` / `--cp-radius-sm` | 18px 玻璃面 / 16px 卡片 / 12px 控件 / 10px 条目 |
| `--cp-glass-blur` | `blur(16px) saturate(1.08)`，仅页面玻璃面与浮层使用 |
| `--cp-surface` / `--cp-panel` / `--cp-panel-muted` / `--cp-panel-solid` | 页面玻璃 / 卡片 / 弱化底 / 不透明浮层 |
| `--cp-border` / `--cp-border-light` | 面板边框 / 行与控件细线 |
| `--cp-text` / `--cp-text-muted` / `--cp-text-light` | 主文本 / 说明 / 弱化 |
| `--cp-highlight-*` | 选中、分段激活、主操作 |
| `--cp-accent*` | 品牌/开启/连接/LED/domain 核心等“状态”语义 |
| `--cp-danger/warn/success/info` + `-bg/-border` | 状态文字与状态条底色/描边 |

**颜色语义**：`highlight` 表示交互选中/主操作；`accent` 表示开启/连接/品牌状态；两者不混用。
**工作台内禁止嵌套 `backdrop-filter`**：页面级只保留一张玻璃面，内嵌卡片使用 `cp-card`。

## 3. SCSS mixin（`src/styles/_ui.scss`）

通过 `vite.config.ts` / `vitest.config.ts` 的 `additionalData` 全局注入，组件 `<style lang="scss">`
直接 `@include`：

| Mixin | 用途 |
|---|---|
| `cp-workspace($pad)` | 页面骨架：8px 留白 + 单张固定玻璃面 + 零区域间距 |
| `cp-region` | 工作台区域：透明、无描边/圆角/投影 |
| `cp-console` / `cp-console-title` / `cp-console-sub` | 页头/面板头控制台与标题排版 |
| `cp-rail-list` | 栏/列表容器：`4/6` 内边距、`gap:1` |
| `cp-nav-row` | 导航/简单行：30px、hover 底色、选中 highlight + inset 竖条 |
| `cp-card($radius)` | 内容卡/分组卡：1px 边框 + 更实底色，无阴影/模糊 |
| `cp-list-row` | 列表行内边距：`10px 12px` |
| `cp-section-label` / `cp-section-title` | 微标签（11px uppercase）/ 分区标题（14px/900） |
| `cp-pill-button($tone)` | 胶囊按钮（default/primary/danger） |
| `cp-segmented` / `cp-segmented-item` | 分段控件 |
| `cp-icon-button` | 透明图标按钮 |
| `cp-inline-status($tone)` | 状态条 |
| `cp-page` | **旧版骨架**，仅保留给居中/引导类页面 |
| `cp-glass-panel` | **浮层玻璃**，仅用于对话框/抽屉/菜单/Toast/popover 等 |

## 4. 共享组件（`src/shared/ui`）

| 组件 | 规格 |
|---|---|
| `PageHeader.vue` | 工作台控制台：8px 10px、14px/700 标题、12px 副标题、右侧操作；无独立玻璃面；保留 `title/subtitle/back/actions/backTestId` 与 `<header data-testid>` |
| `SectionHead.vue` | 28px 图标瓦片 + 14px/900 标题 + 12px 副标题；`--cp-section-head-gap` 控制间距 |
| `panel/PanelGroup.vue` | `cp-card` 分组卡；组头/脚注不画分隔线；组内行由 `PanelRow` 提供节奏 |
| `panel/PanelRow.vue` | `10px 12px`；不画相邻分隔线；hover 只变底色 |
| `panel/PanelSwitch.vue` | `role="switch"` 开关（40×22，开启 accent） |
| `BackButton.vue` | 药丸/小号，全应用统一返回按钮 |
| `EmptyState.vue` | 空状态（图标 / 标题 / 描述 / 操作） |

跨 feature 只能从 `@/shared/ui/*` 引用这些组件；禁止深层引用其它 feature 的 `presentation/components`。

## 5. 页面骨架

- 主窗口页面：根节点 `@include cp-workspace`；顶部 `PageHeader`（或同规格的 `cp-console` 自定义头部）；
  侧栏与内容区使用 `cp-region`，不画底色/描边/圆角/投影。
- 页面滚动优先交给内部内容区（侧栏列表、正文区或列表区）；窄屏堆叠需要整页滚动时，玻璃面固定到
  视口，外轮廓保持稳定。每页只保留一个主要滚动容器，避免嵌套滚动。
- 侧栏宽度按内容保留：设置 240px、插件中心 280px；栏与内容之间 0 间距。
- 阅读型内容列 `max-width: 880px` 居中；数据网格可占满宽度。
- 分区内边距：桌面 `20px 24px 28px`；≤1180px `18px 20px 24px`；≤900px `16px 16px 20px`；
  ≤640px `12px 12px 16px`。页面留白始终保持 8px，不随断点压缩（避免与玻璃面 `inset` 错位）。
- 响应式：≤900px 左右布局转纵向；≤640px 控件与卡片继续压缩内边距，`PanelRow` 上下堆叠。
- 列表：
  - 导航/简单行 30px、`4px 6px` 容器、`gap:1px`；
  - 富内容行（收藏、成员、机架、审计）`8px 10px`；
  - 文件行 44px；表头保留 1px 功能分隔线（控件级），数据行不画分隔线；
  - 行列表不渲染“未读”分隔横条。
- 聊天主窗口：工作台基准实现；四栏共享同一张玻璃面，栏间 0 间距，resizer 8px 宽、左右
  `-4px` 负 margin（净占 0 宽）；消息区 `padding:10px / gap:8px`，气泡 `8px 10px`；
  窄宽度断点使用 `.cp-center` 容器查询（≤520px / ≤400px）。

## 6. 紧凑密度

| 元素 | 规格 |
|---|---|
| 页面/控制台标题 | 14px / 700 display / letter-spacing .02em |
| 控制台副标题 | 12px / 1.5 |
| 分区标题 | 14px / 900 display；图标瓦片 28px、图标 16px |
| 微标签 | 11px / 700 / .12em / uppercase（仅固定英文标签） |
| 普通行标签 | 13px / 600；说明 12px / 1.5 |
| 元信息 / ID / 时间 | mono 11–12px |
| 导航行 | 30px、`6px 8px`、12.5px |
| 富内容行 | `8px 10px`、无分隔线 |
| 文件行 | 44px、`4px 10px`、无行分隔线 |
| 内容卡 | `cp-card`、内边距 10–14px、圆角 16px |

## 7. 控件规格

| 控件 | 规格 |
|---|---|
| 输入/文本域/下拉 | 38px 高、12px 圆角、`--cp-field-*`，focus 用 `--cp-focus-ring` |
| 胶囊按钮 | 32px 高、999px 圆角、12.5px；hover 只变底色/描边/字色 |
| 图标按钮 | 32×32、10px 圆角、静态透明、hover 才加底色/描边 |
| 分段控件 | 容器 12px 圆角 + 3px padding；选项 30px 高、9px 圆角、激活 highlight |
| 开关 | 40×22、开启 accent |
| 状态条 | `cp-inline-status`，12px 文字、12px 圆角、10% 状态底 + 30% 状态边框 |

控件规格不随工作台迁移调整；迁移只改变页面骨架、表面层级、头部与行列表密度。

## 8. 动效与无障碍

- 统一过渡 `var(--cp-fast) var(--cp-ease)`；按钮/行不做位移，消息入场与骨架脉冲保留。
- `prefers-reduced-motion: reduce` 下禁用非必要动画。
- 焦点：`outline: 2px solid var(--cp-highlight-border-strong)` 或 `--cp-focus-ring`。
- 图标按钮必须有 `aria-label`/`title`；替换结构时保留 `data-testid`、`role`、`aria-*`。
- 玻璃面为 `pointer-events:none` 的 `::before`，不得拦截交互；页面滚动区域必须有独立可聚焦/可滚动语义。

## 9. 防回归

- `pnpm run lint:tokens`：`scripts/check-css-tokens.mjs` 扫描 `var(--cp-*)`，未在 `App.vue` 声明即失败。
- 样式契约测试：
  - `src/shared/ui/__tests__/workspaceSkeleton.test.ts`：钉住工作台骨架、共享组件与页面迁移；
  - `src/features/chat/presentation/patchbay/styles/*.test.ts`：钉住聊天四栏、resizer、行列表与窄宽度行为；
  - `src/shared/ui/__tests__/globalOverrides.test.ts`：钉住抽屉根节点透明与内容面板玻璃。
- 改样式前先找现有 mixin/组件；不要复制玻璃面配方或新增 `--cp-text-secondary` 之类别名。
- 页面级只允许一张玻璃面；发现 `cp-glass-panel` 出现在页面区域时，应改为 `cp-region` + `cp-card`。

## 10. TDesign 覆盖注意

- `.t-drawer` 是覆盖全屏的定位根节点（关闭时仍留 DOM，仅内容面板隐藏），**不能**给它加背景或
  `backdrop-filter`；玻璃只加在 `.t-drawer__content-wrapper`。
- TDesign 浮层（`.t-popup__content`）使用不透明 `--cp-panel-solid`，避免半透明面板透出下层内容；
  输入/选择器统一走 `--cp-field-*`。
- 契约测试 `src/shared/ui/__tests__/globalOverrides.test.ts` 已覆盖以上两条。
