# 07｜组件库规格（Patchbay Components）

版本：v1.0  
日期：2026-01-31

## 1. 基础组件（可全局复用）

- `ConnectionPill`
  - Props：`state: connected|reconnecting|offline`、`detail?`、`onRetry?`
  - UI：LED 点 + 文案 + 可选按钮
- `LabelBadge`
  - Variants：`required|failed|update|domain|info`
  - 规则：必须文字 + 形状，不只靠颜色
- `MonoTag`
  - 用于 socket/plugin_id/domain_version 显示，可一键复制
- `ContextMenuSurface` / `ContextMenuItem` / `ContextMenuSeparator` / `ContextMenuLabel`
  - 位置：`src/shared/ui/contextMenu/`
  - 职责：**唯一**的菜单浮层实现（Teleport + backdrop + 视口钳制 + `Esc` 关闭 + 条目/分隔线/分组标签）
  - 外观基准（简洁实心面板）：面板 `--cp-panel-solid`（**不透明**，半透明毛玻璃会让下层内容透出来）+ `1px --cp-border` + 圆角 14px + `--cp-shadow-float` + padding 6px + `min-width: 200px`（可覆盖）；条目 padding `8px 12px` + 圆角 10px + `13px` + hover `--cp-hover-bg`
  - 条目状态：`active`（当前项）/ `danger`（删除类）/ `disabled`（置灰不可点，`aria-disabled`）；`shortcut` 为右侧快捷键提示（仅展示）
  - 交互契约：条目 `mousedown.prevent`（不抢焦点、输入选区不丢失）；组件不自动关闭，动作后由宿主 `close`
  - 层级：面板 `z-index: 10050`、backdrop `10049`（高于对话框，低于图片灯箱/截图遮罩）
  - 采用方：消息右键菜单、频道右键菜单、服务器菜单、服务器 DND 菜单、文件列表右键菜单、全局输入区/选区菜单
  - 规范来源：`docs/design/ui/solution-a-patchbay/ascii/09-统一右键菜单.txt`

## 2. Patchbay 专属组件

- `RackItem`
  - 服务器条目：名称/头像/LED/当前选中
- `PatchPanelHeader`
  - 当前服务器的“面板头”：server_name、socket、required 状态、入口按钮（plugins/settings）
- `PortListItem`
  - 频道/成员列表条目：左侧端口色点（可按频道/权限/状态）
- `SignalStrip`
  - 消息左侧 2px domain 色条（统一渲染）
  - 分组折叠时仅分组首条展示；组内后续消息隐藏色条（保留 2px 槽位列宽，气泡不偏移）

## 3. 插件中心组件

- `ModuleCard`
  - 显示 provides domains（端口）
  - 状态：installed/enabled/failed/update/required
- `ModuleDetailDrawer`
  - permissions（diff 高亮）、source+sha256、contracts/domains、lastError、版本切换
- `ModuleProgress`
  - 映射状态机：install/update/enable

## 4. 聊天输入（Composer Host）

- `ComposerHost`
  - 左：DomainSelector
  - 中：Slot（Core Text / 插件 composer）
  - 上：ReplyBar
  - 右：SendButton + 状态
  - 对接 `docs/design/plugin/PLUGIN-COMPOSER-UI.md` 的 `submit/cancel/dirty-change`
