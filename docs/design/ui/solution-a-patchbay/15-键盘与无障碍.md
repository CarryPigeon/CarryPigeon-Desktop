# 15｜键盘与无障碍（桌面效率 + A11y）

版本：v1.0  
日期：2026-01-31

## 1. 全局快捷键（现状）

组合式快捷键（`Ctrl/Cmd+K`、`Ctrl/Cmd+P`、`Ctrl/Cmd+,` 等）已移除，仅保留：

- `Esc`：关闭所有浮层（菜单/抽屉/Modal/Popover）

聊天输入：
- `Enter`：发送
- `Shift+Enter`：换行

浮层内部按键（保留）：
- 搜索面板：`↑` / `↓` 选择、`Enter` 打开、`Esc` 关闭
- 图片灯箱：`←` / `→` 切图、`R` 旋转、`Esc` 关闭

## 2. 焦点顺序（建议）

主界面（/chat）：
1) Server Rail（RackItem 列表）
2) Channel Rail（搜索 → 频道列表 → 当前用户区）
3) Top Console（搜索/连接状态）
4) Signal Pane（消息列表，可选跳转）
5) Composer Host（domain selector → 输入 → 发送）
6) Members Rail

原则：
- 不要让“纯装饰元素”进入 Tab 序列
- ContextMenu/Drawer 打开后必须 focus trap（并支持 Esc 关闭）

## 3. ARIA 与可读性

菜单：
- `role="menu"`，菜单项 `role="menuitem"`（现有组件可对齐）
- 右键菜单通过鼠标右键触发（键盘 `Shift+F10` 触发已随快捷键清理移除）
- 统一菜单基元（`src/shared/ui/contextMenu/`）：
  - 禁用项渲染 `disabled` + `aria-disabled="true"`，不可点击
  - 分组标签 `role="presentation"`、分隔线 `role="separator"`
  - `Esc` 关闭；菜单条目 `mousedown.prevent`，输入区焦点与选区不丢失
  - 快捷键提示（`Ctrl+Z` / `⌘Z` 等）只做展示，不绑定按键
  - `Shift + 右键` 仅在 dev 构建保留原生菜单（调试逃生舱），生产构建一律屏蔽

Badge：
- required/failed 不仅靠颜色：加 `aria-label` 或文本

## 4. 动效与可访问性

- 所有呼吸/闪烁动效都必须在 `prefers-reduced-motion: reduce` 下关闭。
- 红色闪烁频率避免过快（避免光敏不适）。
