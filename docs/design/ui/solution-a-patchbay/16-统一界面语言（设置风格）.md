# 16｜统一界面语言（设置页风格）

版本：v1.1  
日期：2026-10-18

> 本文档把设置页的视觉语言固化为全应用基准：页面骨架、玻璃面板、分组行、控件规格与语义色。
> 落地实现以 `src/App.vue` 的 token、`src/styles/_ui.scss` 的 mixin、`src/shared/ui` 的组件为单一真源；本文只解释规则与取舍。

## 1. 视觉基调

- **悬浮面板**：页面背景（暖纸/石墨 + 网格）透过 14px 留白可见，内容承载在一级玻璃面板上，面板之间以 4–16px 间距分隔。
- **克制的层级**：一级面板有柔和阴影；内嵌分组/卡片只有 1px 边框与更实的底色，不再叠加阴影。
- **安静的行列表**：一个分组容器 + 行之间 1px 细分隔线；行 hover 只变底色，不做上浮/位移。**聊天主窗口例外**：行列表不画分隔线，仅靠行间距、hover 底色与激活态区分。
- **品牌识别保留**：domain 色条、LED、等宽 ID、大小写字距微标签继续使用；只替换表面/控件/排版语言。

## 2. Token（`src/App.vue`）

| Token | 值/用途 |
|---|---|
| `--cp-page-pad` / `--cp-page-gap` | 14px / 12px，页面骨架与分组节奏 |
| `--cp-radius-lg` / `--cp-radius-card` / `--cp-radius-control` / `--cp-radius-sm` | 18px 面板 / 16px 卡片 / 12px 控件 / 10px 条目 |
| `--cp-glass-blur` | `blur(16px) saturate(1.08)`，一级面板/浮层的统一模糊 |
| `--cp-surface` / `--cp-panel` / `--cp-panel-muted` / `--cp-panel-solid` | 页面玻璃 / 卡片 / 弱化底 / 不透明浮层（菜单） |
| `--cp-border` / `--cp-border-light` | 面板边框 / 行分隔线 |
| `--cp-text` / `--cp-text-muted` / `--cp-text-light` | 主文本 / 说明 / 弱化 |
| `--cp-highlight-*` | 选中、分段激活、主操作（与设置页一致） |
| `--cp-accent*` | 品牌/开启/连接/LED/domain 核心等“状态”语义 |
| `--cp-danger/warn/success/info` + `-bg/-border` | 状态文字与状态条底色/描边 |

**颜色语义**：`highlight` 表示交互选中/主操作；`accent` 表示开启/连接/品牌状态；两者不混用。

## 3. SCSS mixin（`src/styles/_ui.scss`）

通过 `vite.config.ts` / `vitest.config.ts` 的 `additionalData` 全局注入，组件 `<style lang="scss">` 直接 `@include`：

- `cp-page`：页面骨架。
- `cp-glass-panel($radius, $shadow)`：一级玻璃面板（含 `-webkit-` 前缀）。
- `cp-card($radius)`：内嵌卡片/分组。
- `cp-section-label` / `cp-section-title`：微标签 / 分区标题。
- `cp-pill-button($tone)`：胶囊按钮（default/primary/danger）。
- `cp-segmented` / `cp-segmented-item`：分段控件。
- `cp-icon-button`：透明图标按钮。
- `cp-inline-status($tone)`：状态条。
- `cp-list-row`：统一行内边距。

## 4. 共享组件（`src/shared/ui`）

- `panel/PanelGroup.vue`：分组卡（组头/行容器/脚注，支持 `padded`、`headAction`、`footer`）。
- `panel/PanelRow.vue`：设置行（标签+说明+`control` 插槽，根节点透传 `data-settings-item`）。
- `panel/PanelSwitch.vue`：`role="switch"` 开关（40×22，开启 accent）。
- `SectionHead.vue`：面板内分区头（32px 图标瓦片 + 20px 标题 + 13px 副标题 + `actions`）。
- `PageHeader.vue`：页面级头部（返回 + 标题 + 副标题 + 操作），支持 `backTestId` 保留既有 testid。

跨 feature 只能从 `@/shared/ui/*` 引用这些组件；禁止深层引用其它 feature 的 `presentation/components`。

## 5. 页面骨架

- 主窗口页面：`@include cp-page`；顶部需要标题/返回时用 `PageHeader`。
- 有侧栏的页面（设置、插件中心）：左侧 rail 240–280px + 右侧内容，列间距 16px；两侧都是一级玻璃面板。
- 阅读型内容列 `max-width: 880px` 居中；数据网格可占满宽度。
- 响应式：≤900px 左右布局转纵向；≤640px 页面 padding/gap 降为 10px，`PanelRow` 上下堆叠。
- 顶层面板不嵌套 `backdrop-filter`；列表行与滚动容器禁止再加模糊。

**聊天主窗口（无缝紧凑变体）**：`.cp-main` 使用 8px padding + 0 列间距，四栏共享同一张玻璃面板（`.cp-main::before` 承载 `--cp-surface` 底色、`--cp-glass-blur` 背景模糊、18px 圆角与 `--cp-shadow-soft` 投影）；`rail/center` 自身透明、无描边/圆角/投影，栏与栏之间既无间隙也无分割线，外轮廓只由 8px 留白、圆角与柔和阴影承担。栏头/栏脚/搜索区/顶栏/工具条/行列表均不画分割线，行列表 `padding: 4px 6px` / `gap: 1px`；resizer 8px 宽、左右各 -4px 负 margin（净占 0 宽）叠在栏交界处，静态无引导线，仅悬停/拖拽时显示。布局预算按内容盒宽度计算，固定开销 `resizers: 0`、`gaps: 0`（见 `MainPage.vue`）。

- 聊天主窗口的“无分割线”只针对版式；右键菜单分隔线、对话框页脚、输入/按钮/气泡等控件边框保留。
- 消息流不渲染“未读”分隔横条：未读状态只在频道栏未读徽标与托盘计数中体现，消息列表仅按组首/组内间距组织。
- 消息区同步收紧：`padding: 10px` / `gap: 8px`，meta 下边距 4px，气泡内边距 `8px 10px`；窄宽度断点见第 14 篇。

## 6. 控件规格

| 控件 | 规格 |
|---|---|
| 输入/文本域/下拉 | 38px 高、12px 圆角、`--cp-field-*`，focus 用 `--cp-focus-ring` |
| 胶囊按钮 | 32px 高、999px 圆角、12.5px；hover 只变底色/描边/字色 |
| 图标按钮 | 32×32、10px 圆角、静态透明、hover 才加底色/描边 |
| 分段控件 | 容器 12px 圆角 + 3px padding；选项 30px 高、9px 圆角、激活 highlight |
| 开关 | 40×22、开启 accent |
| 状态条 | `cp-inline-status`，12px 文字、12px 圆角、10% 状态底 + 30% 状态边框 |
| 微标签 | display、11px、700、.12em、uppercase（仅固定英文标签） |

## 7. 动效与无障碍

- 统一过渡 `var(--cp-fast) var(--cp-ease)`；按钮/行不做位移，消息入场与骨架脉冲保留。
- `prefers-reduced-motion: reduce` 下禁用非必要动画。
- 焦点：`outline: 2px solid var(--cp-highlight-border-strong)` 或 `--cp-focus-ring`。
- 图标按钮必须有 `aria-label`/`title`；替换结构时保留 `data-testid`、`role`、`aria-*`。

## 8. 防回归

- `pnpm run lint:tokens`：`scripts/check-css-tokens.mjs` 扫描 `var(--cp-*)`，未在 `App.vue` 声明即失败（运行时注入 token 有白名单）。
- 样式契约测试：`src/features/chat/presentation/patchbay/styles/*.test.ts` 以源码声明钉住关键布局/窄宽度行为。
- 改样式前先找现有 mixin/组件；不要复制玻璃面板配方或新增 `--cp-text-secondary` 之类别名。

## 9. TDesign 覆盖注意

- `.t-drawer` 是覆盖全屏的定位根节点（关闭时仍留 DOM，仅内容面板隐藏），**不能**给它加背景或 `backdrop-filter`，否则关闭态会像一层遮罩盖住整页；玻璃只加在 `.t-drawer__content-wrapper`。
- TDesign 浮层（`.t-popup__content`）使用不透明 `--cp-panel-solid`，避免半透明面板透出下层内容；输入/选择器统一走 `--cp-field-*`。
- 契约测试 `src/shared/ui/__tests__/globalOverrides.test.ts` 钉住抽屉根节点透明、内容面板玻璃两条规则。
