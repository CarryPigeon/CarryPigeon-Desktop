# 05｜页面规格：聊天与消息渲染（Patchbay）

版本：v1.0  
日期：2026-01-31

## 1. 消息气泡（以 domain 为第一视觉线索）

每条消息左侧有 2px “Signal Strip”，颜色来自 domain：
- Core:Text → `--cp-domain-core`
- Unknown → `--cp-domain-unknown`
- 分组折叠时与头像一致：仅分组首条展示色条；组内后续消息不再着色条，改由组内垂直间距（12px）承担视觉分隔。

头像（新增/强制）：
- 在 **频道内消息流**（SignalPane / MessageList）中展示发送者头像（圆形 28–32px）。
- 头像用于“快速识别说话者”，不应抢占 domain 信号条的优先级：
  - 建议布局：`Avatar` + `Signal Strip(2px)` + `Bubble`
  - 分组折叠时可仅在组首展示头像（后续同作者消息可隐藏头像以降低噪声）。

气泡结构：
- Meta：头像/用户名/时间（可分组折叠）
- Body：渲染内容（Core 文本或插件 renderer）
- Actions：右键菜单（复制/回复/删除/转发）——与频道/服务器/文件/输入区菜单共用同一套外观（见《07｜组件库规格》）

## 2. 未知 domain 降级（PRD 7.2）

规则：
- 优先显示 `preview`
- 无 preview：显示 “需要插件以解码此信号” 的卡片（不展示 raw data）
- 提供入口：`安装插件` → `/plugins?focus_plugin_id=...`

视觉表达（差异化）：
- 卡片标题：`UNPATCHED SIGNAL`
- domain 与 version 以铭牌形式展示（mono）
- 一根“断开的虚线线缆”作为装饰（可选）

## 3. 回复（reply_to_mid）与 Composer Host

Composer Host 结构（与 `docs/design/plugin/PLUGIN-COMPOSER-UI.md` 对齐）：
- 左：Domain Selector（Core + 插件 domain）
- 中：输入区（Text 或插件 composer slot）
- 上：Reply Bar（显示被引用消息摘要 + 取消按钮）
- 输入区右上工具栏：表情 / 附件 / 截图三个图标按钮，统一 32×32、无描边、18px 线性图标
  （该 18px 自绘线性图标即全应用图标契约的基准实现，见《01｜视觉方向与品牌》§5）
- 右：Send（发送）——内嵌在文本框内部右下角（浮层，`z-index` 高于文本层），
  文本框以 `padding-bottom` 预留其占位；空草稿或发送中禁用，状态文案为「发送中…」

发送按钮层级约定：按钮为绝对定位浮层，始终绘制在文本之上；文本区的预留内边距保证最后一行文字不被按钮遮挡。

失败策略：
- 发送失败：保留草稿 + 提示错误 + 允许重试（不静默吞错）

## 4. 删除=消失（PRD 6.2）

删除动作在 UI 上分两类（名称要清晰）：
- “删除”（硬删除）：删除后消息直接从列表消失
- “撤回”（若服务端概念存在）：等价于删除但可受权限/时间窗口影响（若没有该概念则不展示）

无论哪种：
- 成功：消息立刻移除
- 失败：显示 toast + 可重试（若本地已移除需回滚显示或提示“删除未成功”并刷新历史）

## 5. 窄宽度自适应（面板 / 窗口被压窄）

消息区宽度由中间栏（`.cp-center`）实测宽度决定，因此**缩放窗口**与**拖动 channel-message resizer** 会触发同一套降级。

硬规则：
- 消息区**只纵向滚动**（`.cp-signalPane` = `overflow-x: hidden` + `overflow-y: auto`）。任何横向溢出都视为布局缺陷，不允许出现底部横向滚动条。
- 长文本/引用一律在容器内收敛：`nowrap` + `text-overflow: ellipsis` 的 flex 子项必须显式声明 `min-width: 0`；flex 默认 `min-width: auto` 会拒绝收缩，导致省略号永不生效并把消息行撑破（表现为面板压窄时引用卡片被右缘裁切）。
- 气泡与引用卡片宽度上限为可用宽度（`max-width: min(74ch, 100%)` 配合 `min-width: 0`）。

两级密度断点（容器查询，判定基准为 `.cp-center` 宽度）：

| 面板宽度 | 消息区内边距 / 行间距 | 头像列 | Meta |
|---|---|---|---|
| ≥521px | 14px / 12px | 44px | 12px，下边距 8px |
| ≤520px | 10px / 10px | 40px | 12px，下边距 6px |
| ≤400px | 8px / 8px | 40px | 名称与时间同步 11px，允许换行 |

- 头像徽标固定 36px，故头像列下限取 40px（保留 2px 呼吸），不再下调以免裁切头像。
- 2px 色条槽位与「组内非首条隐藏色条」规则在所有断点下保持不变；`mine` 右对齐须与左侧布局镜像（列宽成对调整）。
- ≥521px 时所有断点规则均不命中，桌面观感与引入本机制前一致。
