# 08｜动效与交互细节（Patchbay）

版本：v1.0  
日期：2026-01-31

## 1. 动效原则

- 只在“关键节点”发力：连接状态变化、模块安装/启用、required 阻止、消息到达。
- 不要到处小动效；保证输入与滚动性能优先。
- `prefers-reduced-motion` 必须尊重。

## 2. 高价值动效清单

### 2.1 连接 LED

- connected：常亮绿（`--cp-accent`）
- reconnecting：琥珀呼吸（`--cp-warn`）
- offline：红色慢闪（`--cp-danger`）

### 2.2 模块插入（Install）

- downloading：线缆颜色从灰变亮（进度条）
- verifying：短促“扫描线”从左到右
- unpacking：模块面板轻微上移 + 端口逐个亮起（stagger）

### 2.3 required 锁扣

- 未满足时：顶部锁扣条轻微抖动（一次）+ 红色边框提示（持续）
- 满足瞬间：锁扣“啪嗒”闭合动画（一次）+ 成功提示

## 3. 交互细节（桌面效率）

- `Esc`：关闭所有浮层（菜单/抽屉/Modal/Popover）
- 消息区：
  - 右键：打开菜单
  - `Del`：删除（受权限控制，需二次确认）
- 右键菜单（统一实现，见《07｜组件库规格》的 ContextMenu 系列与 `ascii/09-统一右键菜单.txt`）：
  - **原生菜单一律屏蔽**（WebView2 / Chromium 的右键菜单不再出现），改由应用菜单承担
  - 输入类控件（`input` / `textarea` / `contenteditable`，含 TDesign 输入框与 emoji 选择器 shadow DOM 内的搜索框）：编辑菜单「撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选」+ 快捷键提示，按可用性置灰（无选区时剪切/复制置灰，只读时仅复制/全选可用）
  - 非输入区且有文本选中：选区菜单「复制 / 全选」
  - 无可用动作：只屏蔽原生菜单，不弹出浮层
  - 组件已自行处理（消息/频道/服务器/文件/贴纸右键）时，全局菜单不接管
  - 仅 dev 构建保留逃生舱：`Shift + 右键` 仍显示原生菜单（便于「检查」元素）
  - 菜单打开时点击 backdrop 或按 `Esc` 关闭；菜单条目 `mousedown.prevent`，不打断输入区光标与选区

> 备注：组合式快捷键（`Ctrl/Cmd+K` Quick Switcher、`R` 回复等）已移除，详见《15｜键盘与无障碍》。
